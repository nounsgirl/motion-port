# MOTION PORT — VMD → VRMA

インストール不要の、オフラインで使うVMD変換アプリです。
アプリ本体は **index.html** の1ファイルです。ネット接続や外部ライブラリは必要ありません。

## 最初の使い方

1. `index.html` をChromeまたはSafariで開きます。別のアプリで開く場合は、右クリックの「このアプリケーションで開く」からブラウザを選んでください。
2. ダンス用の `.vmd` ファイルを画面にドロップするか、ファイル選択欄から選びます。
3. 自動的に変換し、同じ名前の `.vrma` をダウンロードします。ブラウザ側で保存されなかった場合は「VRMAを保存」を押してください。

元のVMDは変更しません。ファイルを外部へ送信しません。保存先はブラウザのダウンロード設定に従います。

VMDが手元になくても「内蔵テストモーションで試す」でプレビューできます。その後「VRMAを保存」で、オリジナルの6秒のテストモーションをVRMAとして保存できます。

## プレビューと調整

- ドラッグで視点を回転し、スクロールで拡大縮小します。
- 再生・一時停止、再生位置の移動ができます。「移動に追従」を外すと、全体の移動も確認できます。
- 「変換設定」で30/60fps、移動倍率、元モデルの腕の下がり角、足IK、表情を変更できます。
- 設定変更後は「設定を反映して再変換」を押してください。元モデルがTポーズなら腕の下がり角は0°に設定します。
- 足が伸びきる場合は、移動倍率を少し小さくして試してください。ただし、元モデルの脚の長さや構造の違いを、倍率だけで解消できるわけではありません。
- 変換レポートに、対応したボーン・未対応項目・設定・警告を表示し、JSONとして保存できます。

## 対応範囲

VMD 0002と旧形式のヘッダー、Shift-JISの日本語ボーン名、全角数字・全角IK表記に対応します。キーはフレーム順に整え、同一フレームは最後の記録を採用します。

標準ボーンの胴体、腕、脚、手指の回転を変換します。「全ての親」「センター」「グルーブ」「腰」「下半身」を標準骨格上で合成し、hips移動を出力します。ボーンのベジェ補間は30/60fpsでサンプリングします。

「左足IK」「右足IK」は標準体型の二関節IKとして計算し、回転アニメーションに焼き込みます。VMD内の足IKのON/OFFも反映します。口の「あ・い・う・え・お」、まばたき、対応するウィンクと一部の表情をVRMAのpreset表情に変換します。

## 近似変換になる理由と制限

**VMD単体には元モデルの骨格寸法や初期姿勢が入っていません。** このアプリでは腰高1m、太もも0.43m、すね0.44mの標準体型を仮定します。PMX/PMDやVRMモデルの読み込み機能はありません。

足の接地、体格差、腕・指の向き、ねじり・補助ボーンの効果は元のMMDと異なる可能性があります。腕のねじりボーンは簡易な階層合成で扱います。元モデル固有の付与回転・軸制限・補助骨格は再現しません。

髪・服・スカートの物理演算、つま先IK、特殊な補助ボーン、カメラ、照明、影、モデルの表示切替、個別の目線は変換しません。hips以外のボーン移動はVRMAに保持しません。未対応の表情・ボーンはレポートに記載します。

プレビューは変換後の標準骨格です。キャラクターの外観表示や、再生先アプリの互換性検証ではありません。VRMAへの対応や表情の割り当ては、実際に使うアプリ・モデルで確認してください。

ファイルは64MB、長さは20分までです。出力サンプル数にも上限があり、長い60fpsモーションは30fpsへの変更または事前の短縮が必要です。

## 検証記録（2026-09-14）

- 自作の6秒のVMDを使い、パーサー、移動方向、回転、補間、IK、表情、GLB構造、破損入力などの16テストに合格。
- Khronos glTF Validator `2.0.0-dev.3.10`: glTF部分のエラー0、警告0。
- ValidatorにはVRMC_vrm_animation拡張自体の検証機能がないため、その情報通知は残っています。メッシュを持たないノードに関する情報通知もあります。
- pixiv `@pixiv/three-vrm-animation 3.5.5` とThree.js GLTFLoaderで読み込み成功。6秒、51回転トラック、hips移動1トラック、表情1トラックを確認。
- ブラウザ操作ツールのローカルURL制限により、実ブラウザでの画面・自動保存・操作は未検証です。実際の配布ダンスVMDや利用先アプリでの再生も未検証です。

## ソース

HTML内の `converter-core` スクリプトに変換処理、その後のスクリプトに画面処理を収めています。HTMLをテキストエディタで編集できます。別の実行環境に依存するライブラリは同梱していません。
